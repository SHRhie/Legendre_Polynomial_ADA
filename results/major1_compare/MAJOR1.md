# Paired same-protocol comparison (Referee 1 / Major 1)

All models share the corrected 2D Helmholtz problem (k0 = 4*pi, [0,1]^2,
single output), a 3x10 architecture, N_b = 200 / N_r = 10000 points
(checksum-identical across models within a trial; independent
initialization/data/feature seed streams: 1234/101234/201234 + trial),
the same loss (boundary weight 150), and Adam 200 steps followed by
L-BFGS-B (maxiter 40000, maxfun 50000, maxcor 50, maxls 50,
ftol = gtol = machine epsilon; no 'factr' option).

**Protocol**: a pilot run (trial 0, `major1_pilot_t0/`, not used in any
statistic) informed the design of six frozen candidate configurations per
model; development used trials {0,1,2} with a pre-specified selection rule
(median of log10 clipped relative L2, clip [1e-12, 1e3]; ties by IQR then
parameter count); confirmation used ten held-out paired trials {10..19}.
This is a pilot-informed, pre-specified development / held-out confirmation
protocol (not a formal pre-registration).

**Candidates (frozen before development)**: TANH and LPA (P=6, N=30):
lr in {1e-4, 3e-4, 1e-3, 3e-3, 1e-2, 3e-2}; fixed Fourier features:
m in {2,3} x sigma in {0.5,1,2} at lr 3e-3; trainable Fourier features:
m in {2,3} x init sigma in {0.5,1,2} at lr 1e-3; SIREN: omega0 in {5,10,30}
x lr in {1e-4,1e-3} (canonical initialization); neuron-wise adaptive tanh:
slope-recovery coefficient in {0, 0.1, 1} x lr in {1e-3, 1e-2} (scale 10,
initial slope 0.1) — the selected configuration uses coefficient 0, so the
tested variant is neuron-wise adaptive tanh without slope recovery.
A target-frequency-informed oracle Fourier mapping (two frequency vectors,
four sine/cosine features) is reported separately as a reference, not as a
baseline.

**Selected configurations**: TANH lr 3e-3; LPA lr 1e-3; fixed FF m=3
sigma=0.5; trainable FF m=3 sigma=1; SIREN omega0=30 lr 1e-3; adaptive tanh
slope-recovery 0, lr 1e-3.

**Headline (median relative L2 over the ten held-out runs; success =
error < 0.1)**: oracle reference 4.2e-6 (10/10); SIREN 3.9e-4 (9/10);
trainable FF 1.6e-3 (7/10); LPA 2.5e-2 (10/10); fixed FF 6.8e-1 (1/10);
tanh 8.3e-1 (0/10); adaptive tanh 1.3e0 (0/10). Paired log-errors favored
SIREN over LPA (Holm-adjusted p = 0.020); LPA was significantly better than
tanh, fixed FF, and adaptive tanh (Holm-adjusted p = 0.0098 each); the
LPA-vs-trainable-FF difference was not significant at n = 10.
